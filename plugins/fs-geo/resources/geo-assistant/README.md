# GEO 助手资源

首期定义：`soul.md` 与 `skills/geo-assistant/SKILL.md`。平台 Agent 的业务系统范围需显式包含 `geo`，主模型由平台模型池选择；采集器自身不调用推理模型。用户/主体和模型配置不写入此资源目录。

这些是待平台管理员审核、保存并发布的助手资源，不是已创建的线上 Agent，也不自动修改旧智能体、发布记录或用户会话。客户端加载当前版本的 Platform 授权快照，并且存在这个 Skill 后才开放受控 GEO 工具执行。

2026-10-21 已通过源码及本机真实豆包到隔离 GEO 的验收；当前已发布的 3.2.1 客户端不含这些新增工具。正式发布资源前须采用确实包含本轮工具的新客户端候选版本，并配置相应最低版本/能力门槛，再做真实 Platform 和安装版验收。

后续能力继续加到同一 GEO 助手，不以每个采集平台另建一个业务助手。源码和安装包、资源发布以及真实安装版验收分别记录。
