# ADR-0020：平台发布智能体，客户端安装与运行

- 状态：已接受，2026-10-21，用户批准实施。
- 背景：旧角色市场安装本地预设，与平台持久智能体目录分离，导致数量、身份与能力状态不一致。
- 决定：平台 Agent ID 是唯一身份；平台管理草稿、不可变发布和授权。客户端显式安装发布版本，并按设备维护当前版本；会话固定版本、执行时重新授权，更新/卸载不得删除工程和历史。
- 兼容：旧 1.0/1.1 快照和已有会话保持，不自动发布、迁移、改写或重绑定旧数据。新增分发契约显式协商，缺失时显示未支持。
- 后果：需要平台持久发布记录与迁移、客户端可靠安装事务和智能体中心、历史版本执行检查与完整业务验收。
- 规格：`docs/specs/agent-distribution-v1.md`；任务：`tasks/agent-distribution-20261021.md`。
