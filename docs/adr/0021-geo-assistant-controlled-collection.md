# ADR-0021：GEO 助手与受控网页采集

2026-10-21。状态：用户已接受，豆包首期本地真实采集与隔离 GEO 回传验收通过；尚未发布/安装新版本。详见 GEO 仓 `docs/GEO_ASSISTANT_VALIDATION_20261021.md`。

复用 fs-geo 承载 GEO 助手工具域，不另建 Agent Runtime 或本地业务库。GEO 云端拥有任务、原文、引用、截图和效果报告；Host 逐次验证 Platform 身份、Agent GEO 业务范围和 GEO 应用权限，使用专用隔离浏览器与持久任务日志。

固定采集步骤由程序执行；模型只能调用有界业务工具，不能提供任意脚本、网址或浏览器目录。账号凭据只留执行节点，未知发送结果不得重问，回传失败只重传持久结果。先豆包网页，再 DeepSeek；首期资源说明可扩展，不把助手命名为单一采集机器人。双方对接契约记录于本仓 `docs/specs/geo-assistant-web-collection-v1.md`。

用户明确分工后，本任务仅调整 Agent 安装版；GEO 服务端和 Platform 的实现与发布交给各自拥有者。Agent 资源、能力门槛和真实授权接口未就绪时，不能将隔离验收结果称为线上完成。
