# 通用视频制作 Agent v1

用户授权：2026-10-20，制作通用视频 Agent，优先免费，完成非 FutureStaff 行业案例、测试和发布体验。

所有权：桌面 fs-video 插件拥有本机制作工程、修订、渲染任务和产物；Platform 仍拥有真实持久 Agent、Soul、Skill 与权限；FutureStaff AI 继续统一文本模型。无数据库 Schema 或共享身份变更，不修改 DSH Core。

输入为场景 JSON：标题、需求、比例、主题、自然旁白、短字幕、固定图形模板、配音与配乐选项。验证后保存不可变修订；修改必须携带真实基础版本。拒绝模型代码、Shell、任意输出路径与远程素材下载。用户素材扩展须另行增加有界导入契约。

工具：create/revise/get/list/render/status/cancel。每项具有 local ToolMetadata、明确设备及原生审批；会话 ID 从原生 ToolExecution 取得。Host 根据 SessionStore cwd 与不可变 Agent 绑定、当前平台身份及重新授权的快照版本解析工作区。租户、用户、Agent 和路径不能由模型指定。退出登录/切换主体会取消运行。工程保存在既有成员/Agent 工作目录，不迁移历史文件。

渲染采用受控 Canvas 动画、系统 Chromium 无头实例、FFmpeg 外部进程、Edge 在线 TTS 和本机生成的音乐。无需付费图像或视频 API。文本使用主体已开通免费模型；不可保证免费时不自动切换付费。首次运行从发布者获取固定 URL、固定 SHA-256 的免费制作依赖，存储在受控本机缓存并复核全部运行文件；无系统级安装，不执行在线安装脚本。配音服务不可用时保留脚本并明确失败。

任务异步返回，只有完整渲染、ffprobe 与产物检查通过才成功。输出 H.264/AAC MP4、WebM 预览、封面、字幕及制作清单。预览以受身份绑定、短期 token 的回环地址服务，支持 Range；不上传公开素材，不自动发布社交渠道。历史项目与版本保留，可从新会话读取和修改。

验收：输入与路径边界、租户/成员/Agent 隔离、版本变化、原生审批、取消、失败、幂等重试；真实免费模型生成社区咖啡店案例并生成修订；实际视频解码及音轨/字幕检查；可移植 Profile、已有成员工作区升级、完整 npm run check、安装包启动与正式更新源签名/回滚验证。
