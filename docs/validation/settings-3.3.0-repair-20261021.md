## 原因及修复

原始 3.3.0 安装资源已经包含全页设置。此前一次性成员代码迁移保留了七个旧文件，其中旧 `client.js` 不含全页设置，也继续展示上游预设分类。成员 Profile 的代码优先于随安装包附带的 alpha Profile；仅检查源码或安装目录无法证明当前成员实际加载的新旧。

七项差异逐项核验：旧客户端中的受控侧栏改动已合入当前源码；managed-settings 的 83 份源内容一致，产物差异来自构建路径；其余差异为声明、映射和注释。完整备份后将成员平台 lib 恢复为本轮候选的完整代码树，没有把当前机器上的未知内容加入客户通用白名单。

升级器现允许“当前代码和已审计历史代码”组成的混合树：完整路径集合必须匹配可信清单，每个文件必须命中相同路径的可信摘要，整体交换前再次检查实际混合树。未知定制、额外文件、缺失文件和链接仍保留。从原始 3.3.0 安装包独立提取并核验其历史清单，供后续安装资源识别。

原始安装包 SHA256：`bc9217bd8e67f2e5cd186e90b979e0f45a4bc45ef8790a9a80a74a4b81fc706e`；原 manifest：`c4e3cfee66f588ec7528eb2e27cded67dbb3461aba22e517c1359fdf8be72a5f`。474 项资源均已核验。

设置导航补回“Agent 市场”，复用当前智能体中心和授权分发服务。保留 FutureStaff、Agent 市场、通用设置，继续隐藏预设分类；不删除底层预设服务或偏好。修正展开账号菜单时的样式优先级，防止真实聊天输入框和轨迹浮层覆盖设置。

设置页与登录门禁订阅同一账号状态，复用现有门禁判定；会话失效时立即关闭设置并恢复登录层交互，不向登录层抢回焦点。真实浏览器夹具覆盖正常刷新、`no_apps`、过期、退出、加载、主体选择、错误及恢复后不自动重开；没有退出真实账号。最终模块日志为 `output/settings-upgrade-20261021/platform-tests-auth-final.log`。
