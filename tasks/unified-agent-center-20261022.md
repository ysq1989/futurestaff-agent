## 界面方案

- 复用 FutureStaff 现有浅色／深色 token、语义按钮和卡片；21st 分类筛选目录只作元数据参考，不引入新组件库。
- 一个中心标题；分类为全部助手、系统助手、通用助手；管理筛选为全部、已安装、可更新；计数随分类和搜索一致变化。
- 浏览目录和本机安装按稳定来源 ID 合并；同名且无明确映射的不同智能体不擅自合并。权限、安装和版本契约沿用原 Host。
- 窄屏工具栏换行、搜索占一行，列表单列；保留键盘焦点、加载、部分错误、空列表、不可安装原因及卸载确认。

组件树：`AgentCenter → TalentMarket → CategoryFilter + InstallationFilter/Search + TemplateTalentCard/PublishedTalentCard + Empty/ErrorState`。两种卡片只是内部适配，产品入口和管理筛选共用。

设计自检：重复入口用单一中心消除；分类与安装状态分开；计数按当前筛选口径；慢目录不阻塞其他来源；历史版本不计入当前安装数。避免新增装饰、颜色和无意义卡片。
