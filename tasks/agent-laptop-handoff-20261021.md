## 修复和实际范围

- 平台角色和 Skills 已聚焦视频制作；通用系统技能副本从该 Agent 移除。能力收紧不是对所有通用本机工具另设一套安全白名单，仍服从既有权限、设备、审批和主体归属。
- 聊天默认模型来自 Agent 策略，显式选择只影响当前会话；业务调用继续使用旧内容版本。旧会话只有在身份、Agent 和旧版本全部匹配时才首次固定模型策略版本，不重写历史工程。
- Windows 制作组件改为按可信成员身份隔离的短缓存，长文件参数使用系统 namespace；工程、修订和输出仍在成员 Agent 工作目录。实际修订任务使用新组件成功完成。
- 私有视频先打开同一认证会话的固定 HTML 播放页，再读取受控媒体资源；没有执行模型生成的页面脚本。短期预览链接在客户端重启或过期后须重新查询，不是永久下载地址。
- 官方 Profile 仅按完整精确库存升级；用户定制、额外文件、链接或身份不符时保留。台式机特殊中间构建只用私有两阶段验证衔接，未进入公开升级白名单。

当前工具链生成图形动效短视频，使用受控 Canvas、Python、FFmpeg、Edge 在线语音及本机合成音乐，本次没有使用 Remotion，也不承诺写实生成或任意素材导入。在线免费语音依赖网络，失败必须如实记录，不静默切收费。其他系统的历史未验收事项不随本次交付统一标完成。
