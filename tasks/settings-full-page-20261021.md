# 全窗口设置页（2026-10-21）

用户要求设置参考 Codex，改为全窗口页面，取消居中弹窗。

## 实现

- 产品层通过现有 `watchSlotComponents` 替换标准 `sidebar.settings` 的组件，保留注册项的注入、子插槽、分类来源和引导步骤，不修改固定 DSH 子模块。
- 设置页占满标题栏下方区域，左侧搜索与分类、右侧独立滚动内容；返回工作台后恢复入口焦点。没有背景遮罩或设置弹窗语义。
- 原有账号、市场、通用设置、预设及顶部工具继续通过原插槽加载。页面打开期间后台聊天保留，但退出键盘导航；原生窗口控件保持可用。
- 窄窗口改为顶部横向分类，沿用浅色和深色主题。打开设置时隐藏原生内嵌系统页，返回后恢复。
- 21st 搜索的 Settings Sidebar Layout 仅作为结构参考，未引入第三方组件或新增依赖。视觉决定记录于 `.21st/design.json`。
