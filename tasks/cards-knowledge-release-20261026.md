# 卡片与知识候选客户端合并发布 3.3.1

用户已于 2026-10-26 授权将知识库相关改动一并提交、推送、部署更新。只发布本仓库桌面产品；本机 Platform 旧副本不作为知识库服务端发布源。

## 范围

包含通用 Agent 卡片、已完成的商品/ERP/图片卡片及运行修复；知识/反馈本地候选、契约和专用确认窗口准备层；保留这些能力依赖的既有 Agent 目录、人才与授权改动。DSH 上游固定不动，不推送用户数据、凭据、原始会话或忽略目录证据。

知识库真实 provider、生产确认 origin 和实际服务端入库尚未实现接通，发布仍默认 not_connected。本轮更新不等于企业知识库端到端上线，不构造假授权或假回执。

## 发布计划

1. 读取实时 Git/feed/trust/安装状态并保留原文件基线。
2. 运行发布前审查；为已验收3.3.0修复树新增完整精确迁移库存，保持定制保护；修复成员包exports的受控升级。
3. 运行产品、桌面、打包及隔离迁移门禁；已知 Windows symlink 权限限制单独记录，不弱化断言。
4. main 精确提交并推送；从干净已推送源码构建3.3.1安装包。
5. 正常退出当前客户端，安装前后核对账号、会话、工程、绑定、图片及其他系统代码；正常启动、重启并实际验证通用卡片与本地候选入口。
6. 本机验收通过后，以原 Ed25519 信任签名清单；旧公开3.2.1作为回退包，生产锁内CAS旧feed/trust并原子切换；完整HTTPS下载验签/摘要验证。

最新结果与具体收据将在 [发布报告](../docs/releases/cards-knowledge-3.3.1.md) 追加；原失败、回退物和证据不覆盖。
