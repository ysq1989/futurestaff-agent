# 电商详情图制作

先加载相邻 commerce-library 技能，读取品牌、SKU、事实和已选用版式。

1. 将客户购买前的问题映射为有证据的模块：商品是什么/适合谁→关键价值→结构与细节证据→使用方式/场景→尺寸规格/包装清单→已确认的服务信息。按商品需要增删，不堆固定模板。
2. 先写模块脚本：每模块一个标题、一个主要信息、依据来源、所需商品图/特写、可展示数字、尚缺证据。功效、检测、认证、销量、质保与比较数据不能由模型补全。
3. 建立整套版式：统一宽度、栅格、标题级别、品牌色、字号和间距。首屏迅速说明价值；长图按手机实际宽度验可读性，规格信息不得缩成装饰小字。
4. 保真商品图/细节由 commerce-product-images 方法制作。商品实拍裁切优先用于关键细节，场景背景按需要生成。每一模块生成前明确引用哪张图和哪条事实。
5. 商品画面与文案、Logo、数字分开制作；可用 commerce_image_compose 进行有界图层合成，保留layout.json，逐模块导出PNG。其他可用编辑工具也可使用。模型整图含字时逐字复核，无法保证文字正确则将文案改为可编辑文字层。
6. 完成模块后再检查整体叙事、重复卖点、色调、留白与拼接。长图交付保留单模块，便于改价/本地化；实际工具不支持长图拼接时明确交付模块和可编辑排版，不能称整张长图已完成。
7. 归档商品依据、模块脚本、文案、图片、可编辑版式、导出成品及审核记录。每个语言/活动版本保留来源与baseVersion，旧版不覆盖，不自动发布商品页面。
