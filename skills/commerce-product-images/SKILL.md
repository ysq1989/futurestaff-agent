# 电商商品图制作

先加载相邻 commerce-library 技能，执行共用资料读取、归档及验收。

1. 确定SKU/款式和真实原图。核对包装、标签、颜色、形状、可见结构及实际随附配件。缺少商品原图时可先交付拍摄/素材计划；不能凭描述生成并宣称真实商品主图。
2. 根据渠道和用途制定图片清单：主图明确展示商品；细节图说明可见工艺/材质；场景图解释实际使用；规格图使用已确认参数。按需求数量，不固定生成一套几张。
3. 优先沿用企业已选用系列的背景、主体比例、光照、视角、留白和配色，保存为可复用规格。新方向先做一张代表性样图，已有明确方向时直接执行，无需多轮方案确认。
4. 选择保真方法：主图与关键标签优先保留真实商品像素，通过抠图/裁切/合成制作；风格与场景可以生成。参考生成不能保证像素级一致，必须对照原图。看不到的背面、内部与配件不补猜。
5. `agent_image_tools` 读取真实能力；`commerce_image_generate` 使用返回的tool、size及允许的referenceImages，传商品原图与明确参考角色。prompt 写清主体事实、不可变项、构图、背景、灯光、尺寸和禁改项；模型由AI系统选择。能力不足时停在可执行拍摄/合成方案，不换用无参考模型虚构商品。
6. 逐图查看实际输出。保留商品区域、修正背景或版式时优先局部编辑/合成，避免全图重绘。对模糊标签、材质、几何变化标注并返修；不得仅靠“高清”“商业级”等词判通过。
7. 按 commerce-library 完成套图版本：原图、成品、shot-list/brief、提示词或可编辑布局、事实对照与修改记录一起归档。用户选用后记录该版本，后续同系列沿用。
