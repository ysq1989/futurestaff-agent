# 创作验收

共用的硬条件：

- 商品轮廓、款式/颜色、数量、包装、Logo、标签与可见结构和真实依据一致。新增细节无来源时不能通过；必要时改用真实商品抠图/裁切与背景合成。
- 卖点、参数、价格、活动时间来自可追溯资料；文字逐字核对，金额与单位单独核对。过期活动版本不直接复用。
- 目标尺寸、格式、语言、移动端可读性与平台要求匹配。只对目标渠道查询必要的现行规则，不能把其他渠道或旧规则当通用标准。
- 记录已检查与未检查项。原图对照、OCR、视频抽帧/音轨分析仅是证据，AI自评不等于人工选用。
- 图片检查裁切、主体遮挡、边缘、阴影/光照、材质失真、排版溢出、小字和Logo。
- 视频检查商品跨镜一致、动作合理、镜头衔接、完整句子、音轨/字幕同步、静音或配音选择、时长/比例/黑帧；仅任务成功和可播放不足以判定业务质量合格。
- 主图/详情图/Banner/视频分别记录业务用途；生成概念图不冒充实拍或真实使用证据。

交付说明：实际成品路径/预览；本轮产物与未完成项；对应projectId/versionId；企业归档saved或待确认；用户可修改的参数或工程文件。正式选用版本与候选版本都保留，后续优先引用选用版及其适用范围。
