# 企业电商 Banner

先加载相邻 commerce-library，读取品牌规范、商品原图、已确认活动信息和历史选用素材。

1. 明确一个传播目标：新品、活动、类目入口或品牌表达。补齐实际投放位置/尺寸、语言、有效期、商品SKU与CTA。价格或优惠未知时保留待填字段，不虚构促销。
2. 用一句主标题表达核心信息，副标题提供必要证据或条件，CTA清楚。根据实际载体安排商品主体与文案区，预留裁切和安全区。已有方向直接制作，方向确实未定时才给少量明显不同的草案。
3. 优先保留真实商品和Logo像素；背景、装饰、灯光气氛按需求生成。需要参考生图时使用 commerce_image_generate，它自动保存该轮产物和实际提示词。
4. 用 commerce_image_compose 或已有编辑工具将背景、商品、Logo、标题、价格与CTA分层。输出PNG与可编辑layout.json；使用企业指定字体及留白。不要用生成模型重绘商标或最终金额。
5. 每个尺寸重新判断构图和文字换行，不能简单拉伸。移动端小尺寸查看标题、条件和按钮可读性；核对文字、价格、单位、活动期限，检测遮挡和裁切。
6. 归档各尺寸成品、文案、原始商品/品牌素材、layout.json、生成请求及质检结果。活动到期素材保留历史，检索复用时更新价格/时间并创建新版本。
